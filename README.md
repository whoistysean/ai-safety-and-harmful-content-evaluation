AI Safety & Harmful Content Evaluation

About This Project

This project demonstrates practical skills in evaluating AI-generated responses for safety, harmful content, refusal quality, and safe alternatives.

What This Project Demonstrates

Through practical exercises, I demonstrate my ability to:

* Identify dangerous and harmful AI-generated instructions.
* Recognize unsafe medical advice.
* Evaluate appropriate AI refusals.
* Assess whether responses offer helpful alternatives.
* Identify judgmental or unhelpful safety responses.
* Recommend safer responses that reduce potential harm.
